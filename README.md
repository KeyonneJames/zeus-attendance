# Zeus Attendance Tracker

Project Description
Zeus Attendance Tracker is a dynamic web-based attendance management application designed to replace inefficient manual sign-in systems commonly used in workplaces, daycare centers, classrooms, and other organizations. Traditional attendance methods such as paper sign-in sheets are prone to human error, lost records, and scalability issues. Zeus solves this problem by allowing users to digitally check in and check out using a clean, responsive interface while securely storing attendance records in a cloud database.
The application uses real-time external timestamp verification through the World Time API to ensure attendance entries are accurate and cannot be manipulated through local device time changes. Users can quickly enter their name, check in or out, and receive immediate feedback confirming their action. Supervisors or managers can also monitor attendance activity efficiently through centralized digital records.
Zeus was built using modern web development technologies including React for the front-end interface, Supabase for database management, and Node.js for backend API functionality. The system is designed with scalability in mind, making it easy to expand with future features such as authentication, user roles, attendance analytics, and reporting tools.
Target Browsers
Zeus Attendance Tracker is designed to function across modern desktop and mobile browsers, including:
Google Chrome (latest version)
Microsoft Edge (latest version)
Safari (latest version)
iOS Safari
Android Chrome
For the best performance and compatibility, Google Chrome or Microsoft Edge is recommended.
